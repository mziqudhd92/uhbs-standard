# UHBS Web (GitHub Pages landing)

React landing site ported from [UHBS-Web](https://github.com/mziqudhd92/UHBS-Web), adapted for vendor-neutral UHBS v4.0 messaging and GitHub Pages (`/uhbs-standard/` base).

```bash
cd web
npm install
npm run dev
```

Production build outputs to `web/dist`. The deploy workflow also builds MkDocs into `web/dist/specification/`.
